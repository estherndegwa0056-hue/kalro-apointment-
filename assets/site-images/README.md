# Website Image Folder

Replace the images in this folder with your own clear photos. Keep the exact filenames used by the website.

The full filename-to-subject list is in the project root file `IMAGE_REPLACEMENT_GUIDE.md`.

Recommended minimum sizes:
- Hero: 2400x1200
- Gallery: 1800x1200
- Products / feeds / chicks: 1400x1000

All website images are clickable and open in a full-screen viewer.
